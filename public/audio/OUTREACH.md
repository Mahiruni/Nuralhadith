# Nur al-Hadith — Audio Rights Outreach

We are building Nur al-Hadith, a free Hadith reading and study application.

We are seeking explicit permission to use human-recorded Hadith recitations in:
- Web/PWA streaming
- Android/mobile app playback
- Technical caching
- User offline download, where permitted
- Redistribution of the original recording, where permitted

## Permission we need

Please confirm, in writing, the rights granted for the recordings:

1. Collection and Hadith numbering edition
2. Hadith number or complete collection
3. Language
4. Reciter
5. Original recording URL
6. Rights holder
7. License name or written permission
8. Whether web streaming is permitted
9. Whether mobile/PWA streaming is permitted
10. Whether offline download is permitted
11. Whether redistribution of the original audio file is permitted
12. Whether commercial use is permitted
13. Required attribution
14. Any technical or branding conditions
15. Permission date and authorized representative

## Our verification policy

Nur al-Hadith does not treat public accessibility as permission to redistribute audio.

A recording is added to the application manifest only when an applicable published license or written permission supports the intended use.

Status values:
- `verified-redistribution`
- `verified-streaming`
- `permission-required`
- `unknown`

Offline download is enabled only for `verified-redistribution` recordings.

A streaming-only permission will never be used to justify bundling or offline download.

## Translation audio

Arabic recitation rights do not automatically grant rights to English, Amharic, Tigrinya, or Afaan Oromo translation audio. Each translation recording must be verified separately.

Machine-generated speech will not be presented as an authentic prophetic recitation.

## Collection rollout

We intend to verify, where available:

1. Sahih al-Bukhari
2. Sahih Muslim
3. Sunan Abi Dawud
4. Jami at-Tirmidhi
5. Sunan an-Nasa'i
6. Sunan Ibn Majah
7. Muwatta Malik
8. Musnad Ahmad

The current Nur al-Hadith Musnad Ahmad data source is a limited indexed dataset and is not presented as the complete printed Musnad. Audio coverage will follow the actual indexed corpus.

## Evidence retained

For every approved recording, Nur al-Hadith should retain:
- License or permission URL/document
- Rights-holder identity
- Attribution text
- Permitted-use statement
- Verification date
- Original source URL
- Optional SHA-256 checksum

This evidence should travel with the source manifest so that every recording can be audited later.

## Important

A statement such as “free to listen,” “available online,” or “free download” is not by itself treated as sufficient evidence for redistribution into the Nur al-Hadith application. We need the applicable terms or explicit permission covering our intended use.

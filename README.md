# Nur al-Hadith — نور الحديث

A calm, mobile-first PWA and responsive web library for reading hadith.

## Production architecture
- Next.js 16 / React 19 / TypeScript
- App Router with real collection, chapter, search, reader and library routes
- Server-side corpus proxy with cache headers
- PWA manifest + service worker + local device persistence
- Responsive Arabic/English reader with adjustable type
- Continuous chapter mode, bookmarks, notes, share, print/PDF, previous/next navigation

## Corpus and provenance
The application uses a server-side Hadith API adapter so the browser does not ship tens of thousands of records in its JavaScript bundle. The default source is Al Furqan's Hadith API, which documents 17 collections and downloadable datasets.

The source currently reports these eight indexed counts:
- Bukhari: 7,277
- Muslim: 7,459
- Abu Dawud: 5,276
- Nasa'i: 5,768
- Tirmidhi: 4,053
- Ibn Majah: 4,345
- Malik: 1,985
- Ahmad: 1,374

That source total is 37,537 across the eight selected books. Do not equate that number with 37,537 universally authentic reports. Collection membership and report-level grading are different concepts.

The public source currently exposes only 1,374 Musnad Ahmad records through this endpoint, so this repository does not falsely label those 1,374 as the complete printed Musnad Ahmad. A truly complete release should plug in a verified/licensed corpus containing the full 26,000+ Musnad Ahmad numbering and a redistributable English translation before claiming complete coverage.

## Search
The search route is an adapter. Set HADITH_SEARCH_BASE to your preferred indexed search service. The default points at a documented public search endpoint; if that service is unavailable, the UI presents a graceful error instead of pretending search succeeded.

For a durable production corpus, use PostgreSQL/Supabase with indexed Arabic and English full-text search, normalized collections/books/chapters/hadiths/grades/narrators, and a verified synchronization job.

## Content integrity
- Arabic text is source data, not generated by the app.
- English is source data; no translation is generated by the UI.
- Grades are displayed only when supplied by the source.
- The reader explicitly identifies when a separate isnad field is unavailable.
- Numbering and chapter structures can differ between editions; the app follows the selected corpus source.

## PWA
The manifest, SVG app icon and service worker are included. Previously visited same-origin pages/API responses are cacheable after first successful retrieval. The service worker is registered on the home page.
